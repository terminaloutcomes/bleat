# Requirements Traceability

## Current scope note

Remote OpenTelemetry export is out of scope on native macOS. The macOS
application does not create App Attest keys, request telemetry tokens, retain
export batches, or send OTLP; the listed remote-telemetry implementation and
evidence remain applicable to iOS.

This file links specification requirements to implementation and verification.
Add a row before implementing a requirement and retain its ID for the life of
the project.

Status values are `not-started`, `in-progress`, `implemented`, and `verified`.
“Verified” means the listed automated test currently passes, or a requirement
explicitly designated for manual validation has recorded release evidence.
`OIDC-001` through `OIDC-006` cover the protocol and browser-session
invariants. Application integration and the live provider matrix are recorded by
`APP-OIDC-001`; the corresponding OIDC implementation issue is closed.

Documentation navigation and contributor procedures are checked by
`mise run docs:check`, website validation, and mdBook rendering. These mechanical
checks do not establish application behavior or refresh historical release evidence.
